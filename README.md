 Work Process Summary

For this assignment, I used CSS Media Queries and the Bootstrap 5 grid system to build responsive web layouts. I started by setting up mobile-first typography and layouts using pure CSS Flexbox and media queries. After that, I brought in Bootstrap elements like the 12-column grid and the responsive navigation bar. Finally, I put everything together into a clean portfolio page, making sure the code is easy to read and works smoothly across mobile, tablet, and desktop viewports.
